# 编程的本质

前面几章完成了 ALU（运算器）和寄存器的搭建，现在将控制信号集中管理，理解"编程"到底是什么。

## 控制信号集中面板

将 8 个控制信号（AO、AI、AC、SO、SUB、BO、BI、BC）集中到一块面包板上，统一为高电平有效（1 = 执行）。

其中 AO、SO、BO 接 74LS245 的 E 使能脚（低有效），AI、BI 接 74LS173 的 G 使能脚（低有效），所以这 5 个信号需要经过 **74LS04 非门**反相。AC、BC 接 74LS173 的 CLR 清零脚（高有效）、SUB 接 ALU 的减法控制，这三个直连即可。

![控制面板面包板](../images/08-programming/control-panel-breadboard.jpg)

在 Digital 软件中，ALU 和寄存器被封装为**子电路**，便于模块化调用：

![Digital 等效电路图](../images/08-programming/control-circuit-digital.png)

## 控制信号表

| 功能 | AO | AI | AC | SO | SUB | BO | BI | BC |
|------|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 寄存器 A 输出到总线 | **1** | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| 寄存器 A 读取总线 | 0 | **1** | 0 | 0 | 0 | 0 | 0 | 0 |
| 寄存器 A 清零 | 0 | 0 | **1** | 0 | 0 | 0 | 0 | 0 |
| ALU 输出到总线 | 0 | 0 | 0 | **1** | 0 | 0 | 0 | 0 |
| ALU 做减法 | 0 | 0 | 0 | 0 | **1** | 0 | 0 | 0 |
| 寄存器 B 输出到总线 | 0 | 0 | 0 | 0 | 0 | **1** | 0 | 0 |
| 寄存器 B 读取总线 | 0 | 0 | 0 | 0 | 0 | 0 | **1** | 0 |
| 寄存器 B 清零 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | **1** |

| 信号 | 全称 | 作用 |
|------|------|------|
| **AO** | A Output | 寄存器 A 输出到总线 |
| **AI** | A Input | 寄存器 A 读取总线（加载） |
| **AC** | A Clear | 寄存器 A 清零 |
| **SO** | Sum Output | ALU 输出到总线 |
| **SUB** | Subtract | ALU 做减法（置 1 时 A − B，置 0 时 A + B） |
| **BO** | B Output | 寄存器 B 输出到总线 |
| **BI** | B Input | 寄存器 B 读取总线（加载） |
| **BC** | B Clear | 寄存器 B 清零 |

> S = Sum（ALU 的和/差输出），SO = Sum Output，SUB = Subtract。

> 表中 **1** = 收到对应控制信号，**0** = 未收到信号。

这些操作**可以组合**，不是某一时刻只能做一件事情。例如：

- 寄存器 A 输出到总线 → 同时寄存器 B 读取总线：`AO=1, BI=1`（对应二进制 `1000 0010`）
- ALU 输出到总线 → 同时寄存器 B 读取总线：`SO=1, BI=1`（`0001 0010`）

## 实例：(5 − 3) + 5 = 7

以具体计算演示"多条指令组合完成一个复杂操作"。

### 第一步：把 5 和 3 分别存入寄存器 A 和 B

先将 DIP 开关设总线为 `0000 0101`（5），`AI=1` → 寄存器 A 存 5。
再将总线设为 `0000 0011`（3），`BI=1` → 寄存器 B 存 3。

> 后续加上内存，这些"手动设值"也可以用指令自动完成。

### 第二步：计算 5 − 3

| 步骤 | 操作 | 控制信号 | 二进制 | 说明 |
|:---:|------|---------|:------:|------|
| 1 | ALU 做减法，结果输出到总线 | `SO=1, SUB=1` | `0001 1000` | ALU = A − B = 5 − 3 = 2 |
| 2 | 寄存器 B 读取总线（存差值） | 保持 `SO=1, SUB=1`，加 `BI=1` | `0001 1010` | B ← 2 |
| 3 | 关闭减法，恢复加法模式 | 保持 `SO=1`，去掉 `SUB、BI` | `0001 0000` | ALU 回到 A + B 模式 |
| 4 | 再做加法：A + B | `SO=1, BI=1` | `0001 0010` | B ← A + B = 5 + 2 = 7 |

> 步骤 3 和 4 之间：关闭 SUB 后 ALU = A + B = 5 + 2 = 7，再让 B 读取总线得到最终结果 7。

## 总结

一个看似简单的问题（5 − 3 + 5），我们大费周章地用控制信号一步步操作。但随着电路组件的增加，可执行的**指令**会变多，我们可以将更多的指令通过**组合排序**去解决更复杂的问题——**这就是编程的本质**：

> 编程 = 通过一组预先定义好的指令（控制信号），操控数据在电路路径上的流动和变换。
